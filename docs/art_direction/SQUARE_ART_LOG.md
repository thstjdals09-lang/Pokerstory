# 광장 아트 시안 — 기록

- 브랜치: `feature/square-art` (플레이테스트 빌드 `playtest/pass1-with-slice`에서 갈라짐). main은 건드리지 않음.
- 방향 B(손그림 2D 동화책). 남의 에셋 없이 Higgsfield `gpt_image_2_5` 생성물과 직접 만든 코드만 사용. 크레딧 약 50 사용.
- 시안 단계에서 멈춤(대표 지시: 너무 자세히 만들지 말고 실행 가능하게 마무리).

## 들어간 것
- 광장 바닥 한 장(레이아웃에 맞춰 칠함), 건물 4채, 관문, 분수, 소품 20종 정도, 채움용 덤불과 화분
- 캐릭터 6명(플레이어, 루미, 모아, 주노, 비비, 미리): 정면·걷기·옆·옆걷기·뒤 5자세. 주민은 가까이 오면 플레이어 쪽을 봄
- 대화 초상화 표정 3종(기본, 웃음, 곤란). 대사에 따라 바뀜
- 양피지 UI(HUD, 대화창, 선택지, 버튼, 안내)
- 카메라 부드럽게 따라가기, 나무·깃발 흔들림, 저녁 반딧불, 벚꽃잎, 분수 반짝임
- 저녁 색조와 창·가로등 빛

## 파일
- 원본: `art_src/square/raw`. 잘라 쓰기는 `tools/art/cut_square.sh`, 최종 그림 만들기와 등록은 `tools/art/build_square_art.py`
- 게임용 그림: `game/assets/art/square/final`, 등록: `game/data/art.json`(sq.*, char.*, ui.*)
- 비교: `square_compare.png`(목표 이미지 대 게임 화면), 움직이는 모습: `square_tour.webp`, 스크린샷: `docs/screenshots/square_art/`

## 시안이라 남겨 둔 것
- 목표 이미지보다 광장이 넓고 성김(건물 배치는 게임 데이터 그대로 둠)
- 머리 위 신호, 이름표, 게시판·가게 안 화면은 기존 그림 방식
- 카드룸·집 안쪽과 다른 장소는 이전 그림(슬라이스) 또는 도형 그대로
- 걷기는 두 자세 번갈아 보이기 수준. 본격 애니메이션 없음

## 확인
- 첫 플레이 흐름 E2E(path_a, path_b)와 슬라이스 흐름 통과

## 시점 조정 (대표 피드백: 바닥은 정수리 탑다운, 건물은 3/4라 따로 노는 문제)
- 비교: `square_view_before_after.png`
- 광장만 적용: 위치 데이터 `village_square.art`에 `tilt: 0.62`, `char_scale: 1.35`, `view_margin_top: 150`, `beyond: sq.grass_tile`
  - tilt: 바닥을 세로로 0.62배로 눌러 약 38도 위에서 내려다보는 3/4 시점으로 그림. 건물·소품·캐릭터는 다시 세워서 찌그러지지 않음. 게임 좌표와 판정은 데이터 그대로라 테스트 영향 없음
  - char_scale: 광장에서만 캐릭터를 1.35배로 그림. 다른 장소는 그대로
  - 광장 한 화면에 거의 전체가 들어오고, 위쪽 지붕이 잘리지 않게 화면 위 여유를 둠
- 걸을 수 있는 곳: 화단·수풀·상자·화분을 부딪히는 물체로 바꿈. 광장 밖은 풀을 어둡게 깔아 경계가 보이게 함
- 남은 점: 바닥 그림은 원래 위에서 본 그림을 눌러 쓴 것이라 돌 모양이 납작함. 이 방향이 맞으면 바닥만 3/4 시점으로 다시 그리면 됨
- 확인: path_a, path_b, path_c, cc04(모든 장소 걷기)와 슬라이스 흐름 통과
