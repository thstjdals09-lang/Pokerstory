# 3D 디오라마 시험 (광장만)

- 브랜치: `feature/diorama-3d` (`feature/square-art`에서 갈라짐). 2D 게임은 그대로이고 `run_game.bat`로 실행.
- 실행: `run_diorama.bat` (Forward+ 렌더러로 이 장면만 실행). WASD 이동, T 낮/저녁, Esc 종료.
- 목적: 3D로 만들었을 때 공간감과 플레이 감각이 더 좋은지 판단. 최종 미술 흉내가 아님.
- 모든 물체는 기본 도형(상자, 원기둥, 구, 삼각기둥)으로만 만듦. 크레딧 사용 없음, 이미지 에셋 없음(UI 아이콘만 기존 것).
- 배치: 2D 광장과 같은 데이터(locations.json)를 1m = 100px로 옮김. 건물 앞면은 카메라 쪽.
- 카메라: 약 40도 내려다보는 원근 카메라(FOV 30), 플레이어를 부드럽게 따라감. 얕은 심도 흐림.
- 조명: 해 그림자, 주변광 차폐, 번짐. 저녁엔 창과 가로등, 건물 앞 불빛.
- 충돌: 건물, 분수, 나무, 화단, 게시판, 부스, 광장 가장자리.
- 스크린샷: `docs/screenshots/diorama_3d/`

## 판단할 것
- 원근 카메라에서 광장의 깊이와 길이 2D보다 잘 읽히는지
- 캐릭터가 건물 사이를 걸을 때의 크기감, 가려짐(나무·건물 뒤로 들어가는 느낌)
- 낮과 저녁 전환의 분위기 차이
- 이동감(속도 3.2m/s, 카메라 따라오는 속도)

## 넣지 않은 것
- 대화, 상호작용, 다른 맵, 게임 로직 연결(말 걸기 안내만 표시)

## 구도 패스 (A 이미지의 카메라 문법)
- 비교: `diorama_composition_compare.png` (A / 이전 / 이후 낮 / 이후 저녁)
- 카메라: 초점거리가 긴 렌즈(FOV 15.5)로 40m 뒤에서 42도로 내려다봄. 앞뒤 크기 차이가 작고 수직선이 안정적임. 화면은 광장에 고정되고 플레이어 쪽으로 조금만 기울어짐
- 배치(3D 화면 전용): 분수를 가운데 두고 뒤쪽에 잡화점·집, 오른쪽에 카드룸, 왼쪽에 회관을 광장 쪽으로 돌려 세움. 건물·문·관문 연결은 게임 데이터와 같음
- 채움: 화단 9개, 가로등 7개, 게시판, 벤치 2개, 부스, 입간판, 상자, 화분, 우편함. 광장 전체를 포장하고 문마다 길을 이음
- 가장자리: 뒤쪽 나무와 울타리, 앞쪽 울타리, 양 앞 모서리의 큰 나무와 덤불, 오른쪽 아래 관문 아치
- 낮 노출을 낮춤(돌바닥이 하얗게 날아가던 문제)

## 직접 조정 (편집 모드)
- 실행 중 F1: 오른쪽에 편집 패널
- 카메라: 거리, 줌(화각), 내려다보는 각도, 좌우 회전, 중심 X/Z, 따라가기 정도
- 건물: ◀ ▶ 또는 건물 클릭으로 선택(노란 고리), 위치 X/Z, 방향, 폭, 깊이, 벽 높이. 드래그로 이동, Q/E로 5도씩 회전. 문으로 가는 돌길은 건물을 옮기면 따라서 다시 깔림
- 마우스: 휠 줌, 오른쪽 드래그 카메라 회전, 가운데 드래그 카메라 이동
- "저장"은 `game/diorama/layout.json`에 기록하고 다음 실행 때 불러옴. "처음 값"은 기본 배치로 되돌림

## 기본값 고정 (대표 저장값)
- 카메라: 거리 11.5, 원근(화각) 53.5도, 내려다보는 각도 20.6도, 중심 (0, -3.2)
- 건물 4채의 위치·방향·크기도 저장값이 기본 배치. "처음 값"도 이 값으로 돌아감
- 카메라 따라가기를 좌우와 앞뒤로 나눔(각각 0~1, 기본 0.55)

## Godot 에디터에서 수정하기
- 최신 저장값(거리 11, 화각 47.5, 각도 24, 중심 (0, -5.2), 따라가기 좌우 0.6·앞뒤 0.75, 건물 4채)을 `game/diorama/diorama.tscn`에 넣음. layout.json은 없앰
- 열기: `edit_diorama.bat` (Forward+로 에디터를 열고 이 장면을 띄움)
- 건물: 씬 트리 `Diorama > Buildings > Home / Shop / CardRoom / Hall`을 선택하고
  - 이동: 뷰포트의 화살표 기즈모를 끌거나 Inspector의 Transform > Position (X, Z)
  - 방향: Transform > Rotation의 Y (다른 축은 무시)
  - 크기: Inspector의 width(폭), depth(깊이), wall_height(벽 높이), door_offset(문 위치)
  - 바꾸면 0.25초 뒤 미리보기가 다시 그려지고 돌길도 문 쪽으로 다시 깔림
- 카메라: 씬 트리에서 `Diorama`(맨 위)를 선택하면 Inspector의 Camera 그룹에 cam_distance, cam_fov, cam_pitch, cam_yaw, cam_centre, follow_left_right, follow_forward_back
  - 게임 화면 그대로 보기: `Camera3D` 노드를 선택하고 뷰포트 위쪽의 "Preview" 체크
- 저녁 미리보기: `Diorama` Inspector의 Preview > preview_evening
- 저장: Ctrl+S. 게임 중 F1 패널의 "저장"도 같은 diorama.tscn에 기록함
- 참고: 미리보기 건물·소품·사람은 저장되지 않는 자동 생성물이라 씬 트리에 보이지 않음. 뷰포트에서 건물을 클릭하면 Diorama가 선택되므로 건물은 씬 트리에서 고름

## 대화 카메라 (루미로 시험)
- 스크린샷: `docs/screenshots/diorama_3d/talk_lumi.png`
- 낮에 광장에 있는 루미 가까이(1.9m)에서 E: 두 사람이 마주 보고, 카메라가 0.8초에 걸쳐 두 사람의 옆쪽으로 부드럽게 이동. 대화창은 게임의 대화창(이름 탭, 표정 초상화, 선택지)을 그대로 씀
- 옆쪽 방향: 두 사람을 잇는 선의 왼쪽/오른쪽 중 광장 안쪽을 바라보는 쪽(뒤로 건물이 보이게), 같으면 가리는 것이 적은 쪽
- 카메라와 두 사람 사이를 가리는 물체(화단, 관문, 덤불 등)는 대화 중에만 숨기고 끝나면 되돌림
- 선택지 "한 판 할래"는 안내 한 줄만, "둘러볼게"나 Esc로 끝나면 카메라가 원래 따라가기 화면으로 돌아옴
- 저녁에는 루미가 카드룸에 가 있는 시간이라 광장에 없음(게임 일정 그대로)
- Godot 에디터: `Diorama` Inspector의 Talk camera 그룹에서 talk_distance(거리), talk_fov(화각), talk_pitch(내려다보는 각도), talk_side(옆으로 도는 정도), talk_lift(두 사람을 화면 위로 올리는 정도), talk_glide(전환 시간) 조정

## 게임 전체 3D 블록 보기 (run_diorama.bat)
- `run_diorama.bat`이 이제 게임 전체를 3D 블록으로 보여 줌(`-- --view3d`). `run_game.bat`은 그대로 2D
- 방식: 2D 월드가 모든 규칙(이동, 충돌, 문, 대화, 알바, 집 꾸미기, 포커, 상점, 저장)을 그대로 돌리고 화면에서만 숨김. `game/scripts/world3d/view3d.gd`가 현재 장소를 locations.json에서 읽어 100px = 1m로 블록을 세우고, 플레이어·주민·신호·초점·알바 줍기 지점·배치한 가구를 매 프레임 따라 그림
- 15개 장소 모두: 광장, 주거 골목, 장터, 숲길, 둔치, 내 집 3칸, 카드룸, 잡화점, 회관, 수선 가게, 찻집, 공방, 방문객 객실
- 중요도 3단계
  - 1: 건물(벽 높이 2.4m, 지붕, 문, 이름), 관문과 출구, 주민(이름, 머리 위 신호), 플레이어
  - 2: 쓸 수 있는 것(게시판, 테이블, 침대, 선반, 표지판): 떠 있는 표식과 이름
  - 3: 장식(나무, 화단, 러그, 등불, 덤불): 낮고 흐린 색, 이름 없음
- 낮/저녁: 저녁엔 창과 등불이 켜지고, 실내는 방 조명. 집에 놓은 등불은 방을 밝힘
- 이전의 광장 구도 시험(A 이미지 배치)은 `edit_diorama.bat`으로 에디터에서 계속 볼 수 있음
- 확인: 모든 장소 방문 시나리오(cc04) 278개, 첫 플레이 흐름(slice) 46개를 3D 모드에서 통과

## 플레이 감각과 공간 다듬기
- 대화: 주민과 대화가 시작되면 카메라가 0.7초에 걸쳐 두 사람의 옆쪽으로 이동. 장소 안쪽을 바라보는 쪽을 먼저 고르고, 건물 안이나 건물 뒤, 방 밖이 되는 자리는 건너뜀. 가리는 나무·등불과 이름표는 대화 중에만 숨김. 두 사람은 서로 마주 봄
- 장소 이동: 들어갈 수 있는 문(건물 문, 관문, 출구 매트)에 다가가면 문이 깜빡이며 밝아짐. 들어갈 때 화면이 어두워지는 동안 카메라가 문 쪽으로 다가가고, 새 장소는 조금 먼 곳에서 내려앉듯 시작
- 걷기: 걸을 때 작은 흔들림, 부드러운 방향 전환, 걷는 방향으로 카메라가 조금 앞서 봄
- 공간마다 구상 하나 (locations.json의 `view3d.concept`, 3D에서만 쓰는 회전 `angle3d`, 건물은 문을 축으로 돌아서 2D 규칙과 문 위치는 그대로):
  - 마을 광장 (village_square): 분수를 중심으로 건물들이 대칭으로 각도를 달리해 분수를 바라본다
  - 내 집 (player_home): 창문 축에 러그와 탁자가 모이고, 침대는 구석에 비켜 아늑한 중심을 만든다
  - 카드룸 (card_room): 조명 아래 한 테이블이 중심이고, 나머지는 벽을 따라 비켜선다
  - 세라의 잡화점 (small_shop): 선반이 V자로 계산대를 향해 손님의 시선을 모은다
  - 내 집 · 작은 방 (player_home_annex): 비워 둔 방: 가운데 러그를 두고 가구 자리가 대칭으로 둘러싼다
  - 내 집 · 모임방 (player_home_hall): 원탁 하나를 중심으로 둥글게 모이는 모임방
  - 마을 회관 (community_hall): 긴 회의 탁자가 방의 축에 놓이고, 전시는 비스듬히 입구를 맞는다
  - 주거 골목 (residential): 큰길을 따라 집들이 조금씩 어긋나게 줄지어 선 골목
  - 장터 (market): 세 가게가 교환대를 향해 부채꼴로 열린 장터 거리
  - 달그림자 숲길 (grove): 오솔길이 숲을 가르고, 쉼터는 길 쪽으로 몸을 돌린다
  - 물안개 둔치 (waterfront): 데크와 정원이 물가를 향해 좌우 대칭으로 열린다
  - 테오의 수선 가게 (tailor): 재단대가 입구를 바라보고 옷감 선반은 벽을 따라 비스듬히 기댄다
  - 리라의 찻집 (tea_house): 카운터 앞에 두 탁자가 좌우 대칭으로 놓인 찻집
  - 비비의 공방 (workshop): 작업대가 방 가운데에서 입구를 맞고, 전시 선반은 구석에서 비스듬히 선다
  - 방문객 객실 (guest_cottage): 침대는 창가 구석, 탁자는 방명록 쪽으로 살짝 돌아 손님을 맞는다
- 2D에도 보이는 변경: 내 집·카드룸·작은 방 러그 위치와 크기, 모임방 원탁 반지름 90→96, 찻집 탁자 반지름 46→52
- 카메라 값: 게임 전체 3D(run_diorama)는 시작할 때 `game/diorama/diorama.tscn`의 Diorama 노드 값(거리, 줌, 내려다보는 각도, 좌우 회전, 흐림, 대화 카메라)을 읽어 씀. `edit_diorama.bat`에서 Inspector 값을 바꾸고 저장하면 다음 실행부터 그대로 적용. 실내는 0.8배 가까이. 현재 값: 거리 31.03, 화각 20, 각도 20.5, 흐림 0.05(앞 8.6m·뒤 11.9m부터). 스크린샷: `docs/screenshots/diorama_3d/game3d_camera.png`

## 게임 3D 카메라 편집 (edit_camera3d.bat)
- `edit_camera3d.bat` → `game/scenes/game_camera_3d.tscn`. 루트 노드 GameCamera3D의 Inspector 값이 run_diorama.bat 카메라(거리, 줌, 각도, 좌우 회전, 실내 배율, 흐림, 대화 카메라)
- 뷰포트에는 게임과 같은 코드(view3d.gd의 build_preview)로 만든 실제 장소가 보임. preview_location으로 장소를 바꾸고, Player 마커를 끌어 서 있는 자리를 정하면 Camera3D를 선택하고 Preview로 게임 화면 그대로 확인
- preview_talk를 켜면 Player와 Resident 사이 대화 카메라를 미리 봄
- 이전의 diorama.tscn 값(거리 31.03, 각도 20.5, 흐림)을 기본값으로 옮김. diorama.tscn은 이제 광장 구도 시험용일 뿐 게임 카메라와 연결되지 않음
