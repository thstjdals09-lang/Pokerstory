# 광장 아트 2단계 — 스타일 가이드 (방향 B: 손그림 2D 동화책)

기준 이미지: `square_targets_v1/B_painted_2d_day.png`, `square_targets_v1/B_painted_2d_evening.png`.
이 문서는 광장부터 적용하고, 다른 장소로 넓힐 때도 그대로 씀.

## 1. 화면과 카메라
- 위에서 비스듬히 내려다보는 정사영 시점(원근 없음). 건물은 앞면과 지붕이 함께 보이는 3/4 시점.
- 1280x720 기준. 광장(1600x1100)의 대부분이 한 화면에 들어가고, 카메라는 플레이어를 부드럽게 따라감(끝에서 멈춤).
- 조작: WASD·방향키, 게임패드 왼쪽 스틱, 상호작용 E·A 버튼. 게임 판정(좌표, 문, 충돌)은 기존 데이터 그대로.

## 2. 크기

## 3. 형태와 붓질
- 형태: 둥글고 살짝 삐뚤어진 손맛. 직선도 약간 흔들림. 과장된 지붕, 두툼한 문과 창틀.
- 윤곽선: 진한 갈색 먹선(#3b2a20 계열), 얇고 부드럽게. 검정 윤곽선은 쓰지 않음.
- 칠: 과슈 질감, 붓자국이 보이는 평면 채색 + 부드러운 음영 1단계 + 하이라이트 1단계.
- 빛 방향: 왼쪽 위에서 오는 따뜻한 햇빛. 그림자는 오른쪽 아래, 보랏빛 갈색 반투명.
- 카드 문양(♠♥♦♣)은 장식으로만: 분수 테두리, 카드룸 간판, 깃발, 게시판 핀. 카지노 느낌 금지(네온, 금색 칩 더미, 슬롯 없음).

## 5. 신호와 강조
- 상호작용할 수 있는 대상은 주변보다 채도를 조금 높임. 상시 이름표는 쓰지 않음.
- 머리 위 신호는 손그림 스타일로 다시 그림: 메인(노란 느낌표 말풍선), 주민 이야기(흰 말풍선 "…"), 부탁(작은 노란 점 "!").
- 가까이 가면 발밑에 붓으로 그린 고리와 종류 표시.

## 6. UI
- 재질: 찢은 양피지(#efe0c2 ~ #e3caa9), 먹선 테두리, 붓으로 칠한 이름 탭(#3b2a20에 크림색 글자).
- 대화창: 아래쪽, 왼쪽에 타원 액자 초상화, 이름 탭, 오른쪽 아래 넘김 표시. 선택지는 대화창 위 오른쪽에 종이 쪽지 모양, 앞에 카드 문양.
- HUD: 왼쪽 위 종이 패널(칩 아이콘 + 칩 수 + 목표 한 줄), 오른쪽 위 종이 꼬리표(해·달 아이콘 + 장소). 메뉴 버튼은 작은 아이콘.
- 안내: 아래 가운데 작은 종이 쪽지 "E  대화하기".
- 글꼴: 지금은 OS 기본 글꼴(맑은 고딕). 손글씨 느낌 글꼴을 쓰려면 무료(OFL) 한글 글꼴을 넣을지 결정이 필요함(남의 자산 사용 여부).

## 7. 제작 방식
- 모든 그림은 Higgsfield `gpt_image_2_5`로 생성. 참조 이미지는 항상 기준 이미지(B 낮)로 두고, 투명 배경으로 뽑음.
- 소품과 자세는 한 장에 여러 개를 모아 뽑고 잘라서 씀(크레딧 절약, 스타일 일관성).
- 바닥은 붓질 질감 견본(풀, 돌길, 광장 돌)을 만들어 반복 이음새를 없앤 뒤, 게임 데이터의 길과 광장 모양대로 칠함. 가장자리는 붓질처럼 불규칙하게 처리.
- 캐릭터는 정면·옆·뒤 세 방향 그림에 코드로 걷기 흔들림, 기울임, 숨쉬기 움직임을 줌. 대화창 초상화는 표정 3종(기본, 웃음, 곤란).
- 파일은 `game/assets/art/square/`, 등록은 `data/art.json`. 게임 로직은 바꾸지 않음.
