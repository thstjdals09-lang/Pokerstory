# 광장 아트 1단계 — 방향 탐색 (목표 스크린샷)

- 범위: 마을 광장 바깥만. 건물 안쪽, 다른 장소는 제외.
- 자산 원칙: 남의 에셋(유료·무료 팩)은 쓰지 않음. 직접 만든 것과 생성형 AI 결과물만.
- 도구: Higgsfield `gpt_image_2_5`(high, 1k, 16:9). 6장, 9크레딧(남은 크레딧 91).
- 같은 배치(광장, 분수, 가게, 집, 카드룸, 회관, 게시판, 관문)와 같은 인물(플레이어, 루미, 모아), 같은 UI 요소(칩, 목표, 장소, 안내, 대화창)로 세 가지 스타일을 비교.

## 제작 가능성 (남의 에셋 없이, 생성형 AI + 직접 제작)

| | A. 3D 디오라마 | B. 손그림 2D | C. HD 픽셀 |
|---|---|---|---|
| 게임 엔진 쪽 | Forward+ 3D로 화면을 새로 만듦(판정은 기존 2D 좌표 유지) | 지금 2D 구조와 그림 목록(art.json)을 그대로 씀 | 2D 구조 그대로, 조명 효과 추가 |
| 건물·소품 | 이미지→3D 생성(크레딧 소모, 형태 정리 필요) | 투명 배경 스프라이트로 하나씩 생성, 참조 이미지로 스타일 고정 | 생성은 되지만 픽셀 격자가 어긋나 정리 필요 |
| 캐릭터 동작 | 리깅과 애니메이션을 직접 만들어야 함(남의 동작 자료 사용 불가). 가장 큰 위험 | 몸 부위를 나눠 그려 코드로 움직이는 인형 방식. 해낼 수 있음 | 프레임마다 그려야 함. AI로 일관성 유지가 어려움 |
| 조명·저녁 | 엔진 조명으로 가장 쉽고 좋음 | 2D 조명과 색조로 가능(슬라이스에서 이미 검증) | 2D 조명 + 번짐 효과로 가능 |
| 크레딧 | 가장 많이 듦 | 이미지 50~60장 예상, 남은 크레딧 안에서 가능 | B와 비슷 + 정리 작업 |
| 완성도 상한 | 가장 높음 | 높음(스타일 일관성이 관건) | 높음(정리 품질이 관건) |
