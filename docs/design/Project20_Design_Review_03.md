|---|---|---|

| 포커 참가금 | 20 | 20 |
| 승리 / 무승부 / 패배 순손익 | +20 / 0 / -20 | +20 / 0 / -20 |

- 기존 저장 파일의 잔액은 바꾸지 않습니다. 시작 칩 변경은 신규 게임에만 적용됩니다.
- 이번 값은 첫 프로토타입의 경제 조정이며, 최종 밸런스가 아닙니다.

## 3. 강제 종료 후 포커 복원 방식 (D2)

**원칙:** 판이 시작되는 순간 참가금과 카드가 **함께** 저장됩니다. 재실행하면 같은 판이 같은 상태로 다시 열립니다. 강제 종료로는 결과를 바꾸거나 참가금을 돌려받을 수 없습니다.

| 시점 | 저장 내용 |
|---|---|
| 판 시작 | 참가금 차감(`poker_stake`) + `pending_poker_stake = 20` + 진행 중인 판 전체(`poker_in_progress`)를 한 번에 저장 |
| 별빛 감각 사용 | 사용 횟수와 결과를 판 데이터에 저장 |
| 교체·승부 | 교체 → 루미 교체 → 판정 → 정산 → 진행 중인 판 삭제를 한 번에 저장. 이 과정은 중간에 멈추지 않는 한 덩어리입니다. |
| 포기 (D1) | 진행 중인 판 삭제, 참가금 반환 없음 |

**`poker_in_progress`에 저장하는 것:** 플레이어 손패 5장, 루미 손패 5장, 남은 덱 42장의 순서, 덱 시드, 교체 한도, 진행 단계(교체 전), 능력 사용 횟수와 결과.

**재실행:** "이어하기"를 누르면 카드룸으로 돌아간 뒤 포커 화면이 바로 열리고 "중단된 판을 이어서 해요. 참가금은 이미 걸려 있어요."라고 안내합니다.
- 손패, 루미 손패(뒷면), 덱 순서, 능력 사용 여부와 결과가 그대로입니다.
- 새 손패를 받지 않고, 참가금도 다시 차감하지 않습니다.
- 교체할 때 받는 카드도 저장된 덱 순서에서 나오므로, 종료 전과 결과가 같습니다.

**교체 전에 선택만 해 둔 카드:** 확정 전 선택 상태는 저장하지 않습니다. 재실행 후 다시 고르면 됩니다. 선택만으로는 덱이 바뀌지 않으므로 결과에 영향이 없습니다.

**창 닫기:** 이전 빌드는 창을 닫으면 포기로 처리했습니다. 이번 빌드에서는 판을 그대로 저장하고 재실행 시 이어서 하게 했습니다. 창 닫기와 프로세스 강제 종료를 같게 취급해서, 종료 방식에 따라 유불리가 생기지 않게 하기 위해서입니다. 포기는 게임 안의 "나가기" 버튼으로만 할 수 있습니다(D1).

**복원할 수 없는 경우:** 저장된 판 데이터가 손상되어 52장이 맞지 않거나 카드가 중복되면, 환불하지 않고 저장 파일을 "손상됨"으로 거부합니다. 파일은 수정하지 않습니다.

**이전 빌드(v2)의 저장 파일:** 참가금은 차감됐지만 카드가 저장되지 않은 v2 저장 파일은 재실행 시 이미 낸 참가금으로 **새 판을 한 번** 배분합니다. 환불도 추가 차감도 없습니다. 이 경우만 새 손패를 받습니다(4절 참고).

저장 형식은 v3입니다. v1과 v2는 자동 변환하며 잔액은 유지합니다.
