# 3막 네잎 저녁제 / 후일담 세부 플로우

## 기여 토큰
2막 완료 후 `story.contribution_ids`가 빈 집합으로 시작한다. 동네 전달 의뢰/공공사업/축제 준비/첫 포커 참가/관전 봉사 등 서로 다른 5~8개 중 **고유 ID 3개**를 골라 완료. 같은 아르바이트 3번 반복으로 3개를 채울 수 없지만, 포커 한 번도 치지 않아도 생활·교류 3개로 가능. 기여 상황은 게시판에 0/3~3/3으로 표시.

## S8: 주민 회의
미리: “칩으로 살 수 있는 건 천막뿐이네요. 와서 앉아 줄 사람은 어떻게 모으죠?” 노아: “초대장을 보내요. 포커를 몰라도, 할 일이 없더라도 와도 된다고요.” 플레이어는 무대 장식 중 하트/클로버/다이아/스페이드에서 하나를 고른다. 이는 미적 장식·대사 차이만 만들고 필수 포커 규칙을 바꾸지 않는다.

## S9: 축제 당일
광장 행사 게시판에서 언제든 `축제 시작` 선택 → 주노의 짧은 개막 멘트 → 주민들의 모임 선택: `관전`, `포커 참가`, `정리 돕기`, `모두와 인사`. 활동 하나만 해도 공동 축제 종료 이벤트에 도달. 선택하지 않은 활동은 이후 재개최 때 접근. 플레이어가 포커에서 패배/칩 부족/관전을 선택해도 동일한 메인 엔딩 플래그 획득. 우승/추가 기념품은 별도 수집 목표.

## S10: 후일담 아침
집에서 아침 선택 → 루미 “누가 이겼는지는 잘 모르겠어. 다들 다시 오겠다고 했거든.” 카일 “규칙판 옆에 빈 자리를 남겨 두었습니다. 다음 사람을 위해서요.” `story.act3_complete=true`, `story.postgame=true`; 주민 고정 대사 1종/새 일상 대사 1종, 축제 재개최 버튼/집 꾸미기/수집은 지속.

## QA
축제 장식 구매 비용이 부족해도 주민의 기본 장식으로 개최 가능. 세이브 복원 시 행사 선택 상태와 기념품 지급 id 보존. 현실 날짜·주말·온라인 접속 강요 없음.
