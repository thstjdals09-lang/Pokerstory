# 마을 생활·축제·계절 운영 규칙

## 네 문양과 일상
광장 표지판/가구/소장품으로 네 문양을 사용하되 플레이어에게 한 문양을 영구 선택하게 하지 않는다. 하트 모임은 음식과 환대, 클로버 모임은 우연한 만남, 다이아 모임은 만들기/수선, 스페이드 모임은 새로운 기술/경쟁이라는 주제별 행사다. 주민은 한 행사에 고정 종속되지 않는다.

## 시간 설계
현재 구현 `day/evening` 유지. 플레이어가 카드룸 앞에서 저녁까지 기다리거나 집에서 쉬면 시간대 전환. 지역 입출입으로 시간 초기화 금지. 정해진 시간이 아니면 ‘다음 저녁에 만나기’ 같은 직접 전환 버튼 제공. 축제는 개최 버튼을 누를 때 진행하므로 현지 시각·네트워크·현실 날짜 의존 없음.

## 상시 콘텐츠와 선택 행사
| id | 행사 | 조건 | 재참여 |
|---|---|---|---|
| evt_home_table | 주민 홈게임 | 친밀도 관련 소사건 1개 완료 | 언제든 저녁 선택 |
| evt_card_room | 저녁 카드룸 | 시작부터 가능 | 무제한 |
| evt_square_mix | 광장 교류 포커 | 1막 완료 | 언제든 저녁 선택 |
| evt_fourleaf | 네잎 저녁제 | 3막 완료 | 재개최, 한정 보상 중복 지급 방지 |
| evt_sky_lantern | 등불 산책 | 주민 4명과 인사 | 낮/저녁 원하는 때 재참여 |
| evt_swap | 카드·가구 교환회 | 시장 게시판 해금 | 언제든 요청 가능, 실사용자간 거래 없음 |

현실 날짜 이벤트는 **후속 별도 기능**이다. 콘텐츠 완성 기준에 포함하지 말고, 설계상 `event_availability` 인터페이스만 확장 가능하게 둔다.
