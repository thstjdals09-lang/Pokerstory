# 네잎 저녁제의 짧은 토너먼트 / 직접 승리 비필수

## 소규모 축제 구조
마을 축제 3막에서 ‘관전/참가/행사 돕기’ 세 경로를 연다. 참가하려면 **일반 카드룸과 동일한 기초 원드로 룰**로 3명의 NPC를 순차 대전한다. 새 노리밋 베팅 엔진은 만들지 않는다. 한 판당 20칩 참가/동일 정산이며 판 사이 자발적 종료 가능. 현실 날짜·타이머·온라인 대결 없음.

| 단계 | NPC | 플레이 외 선택지 | 첫 완료 기억 |
|---|---|---|---|
| 예선 | 렌 | 관중 좌석 정리/응원 대사 | `festival.qualifier_seen` |
| 중간 | 리라 또는 테오 | 찻집 전달 의뢰 | `festival.middle_seen` |
| 마무리 | 카일 | 행사 규칙판 정리 | `festival.final_seen` |

## 보상과 재참가
우승은 비화폐성 장식(등판·카드 뒷면) 1회 지급. **메인 스토리 완료, 집 확장, 필수 아이템은 우승 조건으로 잠그지 않는다.** 포커를 전혀 하지 않아도 같은 축제 후일담을 볼 수 있고 별도의 행사 도우미 기념품 획득 가능. 참가금이 부족하면 언제든 아르바이트 복귀/나중에 재도전.

## 복원
각 판은 기존 pending hand 복원 계약을 따른다. 판 사이에는 `tournament_stage`와 이미 지급된 보상 id 저장; 게임 종료 후 같은 단계로 재개. 패배/포기 후 재도전 시 이전 완료 지급 항목 중복 없음.
