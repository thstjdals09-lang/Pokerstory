# 포커 모드 3종 + 별도 연습 (기존 원드로 유지)

## 공통 핵심 엔진
52장 조커 없는 5장 포커; 플레이어·상대 각 5장, 교체 최대3장 1회, 최종 5장 족보 순위·킥커·무승부 검증. 플레이어의 숨은 카드는 상대 AI가 알 수 없다. 능력·모드 추가가 기존 확정/재개/정산/복원 규칙을 깨뜨리면 안 된다. 실제 홀덤의 베팅/블라인드/사이드팟은 이번 범위가 아니다.

| mode_id | 장소 | 형식 | 참가/보상 | 포커를 하지 않는 플레이어 대응 |
|---|---|---|---|---|
| mode.practice | 카드룸·게시판 | 안내와 샘플 족보, AI 상대 연습 | 참가 0, 칩 보상0; 손패 교육 | 처음부터 언제든 선택 |
| mode.homegame | 카드룸/플레이어 집 | 기존 1:1 원드로 | **20 참가, 승+20/무0/패-20 순손익** | 포커 외 의뢰/일거리로 동등한 경제 복구 |
| mode.social_mix | 광장/찻집 | 매 판 NPC 1명을 선택하여 1:1; 관전자 대사 2~3명 | 기본 참가20, 기존 정산 사용 | 관전/대화만으로 관계 이벤트 접근 가능 |
| mode.friendly_challenge | 카드 정원 | 루미/카일 등 라이벌과 1:1; 같은 룰에 능력 loadout 선택 | 기본 참가20, 승패에 추가 영구 보너스 없음 | 경쟁 불참으로 메인 스토리 막지 않음 |

공개 행사/축제의 대회 모드는 `04_TOURNAMENTS.md` 참조. 이번 단계의 3종 모드는 화면/서사 차이는 있지만 **룰 엔진은 하나**이며 성급히 새 포커 게임을 여러 개 추가하지 않는다.

## 참가·종료 계약
참가금 검증/차감과 손패·덱 저장은 원자적. 자발적 게임 내 포기만 손실, 창 닫기/메뉴 종료/프로세스 종료는 **같은 판** 이어하기. 구버전 v2 예외만 1회 배분, v3+ 진행 판은 재셔플 금지. 능력·모드·상대 NPC가 바뀌어도 이 계약 유지.
