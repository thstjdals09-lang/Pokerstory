# 포커 규칙·기술 검증 시나리오

## 기본 불변식
표준 52장 한 벌, 동시에 같은 카드 두 장 없음, 5장씩 배분·한 번 최대 3장 교체·남은 덱 순서 저장. 일반 5장 족보와 킥커/휠(A-2-3-4-5)/동점 판정은 기존 검증 통과 범위를 보존. 특수 능력은 결과를 강제로 뒤집거나 상대의 전체 숨은 패를 공개하지 않는다.
