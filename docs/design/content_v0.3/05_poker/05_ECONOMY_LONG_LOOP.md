# 칩 경제·수집·관계 간 장기 순환

## 근간
포커는 승+20/무0/패-20(각자 20 출자). **승리 기대가 플러스라고 보장하지 않는다.** 게임 경제의 필수적 지속 수급처는 광장 정리와 신규 생활 일거리, 일회성 의뢰는 처음/관계 소개 보너스. 포커 패배 위로금 및 첫 참가 보너스 없음.

## 칩 유입/유출 표
| 유입 | 유출 | 기획 효과 |
|---|---|---|
| 생활 일거리 반복 +10~12 | 기본 가구/의상/카드 외형 | 포커를 안 해도 꾸미기 가능 |
| 최초 의뢰 +15~30 | 집 확장 90/180/320 | 집 성장 중기 동기 |
| 포커 승리 상대분 +20 | 포커 패배 참가금 -20 | 승부의 의미, 파산 회복 경로 보장 |
| 상시 행사 기여 중 일부 최초 보상 | 공공사업30~160 | 개인 집/마을 공동체의 선택 |

## 피해야 할 상태
- 신규 저장/구세이브에 재접속 보너스 중복 지급.
- 승패 후 지급액이 메인 스토리 기여 점수로 반복 환산되어 무한 해금.
- 모든 칩을 집에 쓰면 스토리·기본 대화·광장 정리 접근 불가.
- 주민 친밀도를 올리려면 포커에서 이겨야만 함.

## 수치 변경 게이트
경제 시작40/입장20/등불50 등 기존 승인값은 잠금. 새 아이템/공공사업 수치는 플레이 시간 데이터 전 가설. 검증 시 ‘생활 활동 1~2회 → 가구 1개’, ‘집 확장 1회에 몇 번의 일거리’ 등을 실제 동선 기준으로 보고하고, 체감상 지나치게 반복적이면 **새 콘텐츠 값**을 조정한다. 실돈이나 현금성 보상은 추가하지 않는다.
