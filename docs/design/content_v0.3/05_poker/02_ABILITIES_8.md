# 판타지 포커 능력 8종 — 단일 패 상태 엔진 위의 선택

기존 `ability.starlight_sense`의 실제 ID가 다르면 기존 ID를 보존하고 이 문서의 별칭만 매핑한다. **숨은 정보 전체 공개, 완전한 덱 순서 변경, 결과 강제 역전 능력은 금지.** 능력은 캐주얼한 정보·선택으로 재미를 더한다. 기본 한 판 1회, 교체 확정 전에 사용 가능; 상대별로도 동일 정보 제한 원칙.

| ability_id | 이름 | 플레이어에게 보이는 효과 | 원리/테스트 가능한 제한 |
|---|---|---|---|
| ability.starlight_sense | 별빛 감각 | 상대 현재 5장이 원페어 이상인지 예/아니오 | **기존 능력**; 상대 전체 손패/향후 교체 결과 공개 안 함 |
| ability.suit_echo | 문양의 메아리 | 내 현재 패에서 가장 많은 문양과 그 장수 표시 | 자기 손패에만 기반한 편의 정보; 확률 조작 없음 |
| ability.discard_hint | 조심스러운 메모 | 교체 선택 전 내 보유 족보와 버릴 카드의 예상 족보 변동 *가능성* 도움말 | 최종 카드 결과 예측/보증 금지; 같은 입력 같은 안내 |
| ability.steady_hand | 차분한 손 | 선택한 교체 카드 목록을 확정 전 1회 되돌림 | 덱 소비 전 UI 선택 취소만; 확정 이후 재시도 안 됨 |
| ability.table_read | 테이블 읽기 | 상대가 이전 판에서 몇 장 교체했는지 기록 열람 | 이미 공개된 과거 행동만 사용; 현재 비공개 손패 제외 |
| ability.lucky_mark | 작은 표시 | 내 카드 1장에 시각적 표시를 남겨 실수 교체 방지 | 카드 값/승률을 변경하지 않는 UI 잠금 선택 |
| ability.pattern_book | 패턴 수첩 | 상대가 공개적으로 자주 유지하는 족보 경향을 텍스트 설명 | 누적 **공개된** 이전 판의 행동만 반영, 숨은 덱 상태 금지 |
| ability.friendly_pause | 숨 고르기 | 한 판 중 선택 화면에 족보 도움말 강조/설명 추가 | 타이머가 없는 게임에서 강제 이득 없음; 접근성 능력 |

## 능력 잠금·선택
첫 플레이에서는 별빛 감각을 유지한다. 다른 능력은 주민 첫사건/소장품으로 순서 없이 얻고, 한 판에 loadout 1개를 고른다. 새 능력이 ‘무조건 승리’나 0칩 회복을 만들지 않는다. 플레이어의 선택을 유발하는 8종의 **기획 초안**이며 재미 없는 UI 도움만 존재할 경우 실제 플레이에서 교체 가능하게 데이터로 분리한다.

## 상태/검증
`ability_id`, `used_count`, `result_payload`, `phase_at_use`를 pending poker state에 저장. 종료·재실행으로 같은 능력 반복 또는 다른 결과 획득 불가. 상대 AI는 상대가 알 수 있는 공개 정보·자신 카드만 사용. 표시 능력의 경우 게임 규칙상 비공개 정보가 UI에 새지 않는지 테스트.
