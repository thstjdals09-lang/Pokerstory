# 관계 모델 — 친구/라이벌/연애/공동체

## 상태 구조
```yaml
resident_relation:
  resident_id: npc_lumi
  friendship: 0 # 0..100; 처음 인사 5, 개인사건 +8, 반복 일일대화는 무제한 파밍 금지
  rivalry: 0 # 0..100; 경기 참가·정당한 경쟁 통해 상승, 우정과 공존
  memories: [] # event_id set; 선물과 첫 집 초대 기록
  romance: {eligible: false, consent: false, stage: closed} # 성인/대상 지정만 가능
npc_edges: # 허용 목록에 있는 pair_id만
  - {pair_id: lumi_kyle, phase: strained, source_event: story.act2_start}
```

## 관계 단계 및 인터랙션
| 축 | 조건(테스트 가설) | 해금·반응 | 강제 없음 |
|---|---|---|---|
| friendship 0–19 | 인사/기초 의뢰 | 반복 대화, 공용 모임 | 처음부터 포커/일상 이용 가능 |
| 20–49 | bond_01 | 홈게임 초대, 편지 | 별도 보상 농장 아님 |
| 50–79 | bond_02 | 집 방문 반응, 기념품 | 메인 3막 필수 아님 |
| 80–100 | 개인 후일담 | 전시·칭호·재방문 대사 | 더 이상 큰 수치 파밍 불필요 |
| rivalry 20+ | 공정한 대전 횟수 | 재도전 대사·특별 모임 | 포커 패배로 우정 페널티 없음 |

## 연애 (루미/카일/리라/테오, 성인으로 설정)
- 플레이어가 명시적으로 ‘더 알아가고 싶다’ 선택 → `romance_consent=true`, 주민 관계 조건/개인 사건 충족 시 데이트. 자동 진입 금지.
- 거절하거나 선택하지 않아도 우정·메인 스토리·모든 공공사업 이용 가능. 플레이어가 관계 종료를 선택하면 `romance.stage=closed`, 이미 획득한 일반 아이템은 회수하지 않는다.
- 동시 연애 처리: 자동 질투/벌금 없음. 관계 진전은 개인 루트별 동의와 대사로만. 결혼·출산·성적 콘텐츠는 이번 범위 밖.

## 주민 간 관계
허용된 `npc_edges` 8~12개만 관리. `neutral → bonded/strained → reconciled` 전이는 사건 플래그로 발생. 매 프레임 무작위 호감도 시뮬레이션 금지. 플레이어는 대화를 통해 이웃 관계를 관찰하지만 타인 감정을 완전히 조종하지 않는다.
