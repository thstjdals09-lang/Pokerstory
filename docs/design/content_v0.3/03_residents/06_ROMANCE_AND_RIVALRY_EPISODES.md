# 선택형 연애 4루트 · 라이벌 4루트

## 공통 전제
연애 가능 주민 루미/카일/리라/테오는 모두 명시적으로 성인. 최초 친밀 사건2 완료 및 플레이어의 **명시적인 연애 선택** 후에만 루트 열림. 루트 진입/거절/종료는 메인 스토리, 직업, 포커, 공공시설 접근에 영향을 주지 않는다. 플레이어가 고백하지 않는 한 주민이 자동 연애 상태로 전이하지 않는다.

| 대상 | 선택형 데이트 1 | 데이트 2 | 관계 진전 장면/중단 선택 |
|---|---|---|---|
| 루미 | 저녁 광장에서 포커 아닌 산책, 누가 이겼는지보다 같이 있었던 시간을 말함 | 집의 등불 옆에 차를 두고 대화 | “우리 둘의 모임도 좋겠어” / “친구로 지내고 싶어”; 후자 선택 시 우정 유지 |
| 카일 | 찻집에서 오래된 규칙책의 낙서 찾기 | 카드 정원에서 서로 다른 모임의 장점을 이야기 | “함께 새 규칙을 만들어 보고 싶어” / “동료가 좋아”; 포커 승리 필수 아님 |
| 리라 | 손님 없는 찻집에서 향기 취향 비교 | 둔치에서 저녁 간식 나누기 | “다음에도 둘이 만날래?” / “평소처럼 지내자”; 관계 선택은 반복 강요 금지 |
| 테오 | 수선 가게에서 오래된 스카프 고르기 | 주거 골목에서 행사 천막의 모양 고르기 | “함께 맞춰 보자” / “친구로 충분해”; 단일 호감도 강제 분기 아님 |

## 라이벌 루트
루미/카일/렌/주노 각 1회 개인 라이벌 장면: 세 번의 **공정한 포커 참가** 또는 주민 사건을 통한 모임 준비 완료 후 경쟁 이야기가 열린다. 승리 횟수 3회 요구 금지. 포커를 전혀 안 해도 메인 스토리 진행과 해당 주민 기본 친밀 사건 열림. 우승에 실패하면 재도전 가능, 패배했다고 친밀 수치 감소/다른 콘텐츠 봉쇄 없음.

## 저장 상태
`romance.consent`, `romance.stage`, `romance.seen_dates[]`, `rivalry.scene_seen` 별도; 중단 후 선택 결과 재발행 방지. 관계 종료 시 연애 UI/대사는 변경하지만 소장품 강제 회수·의무적인 이별 이벤트 강요 금지.
