# 주민별 개인 사건 32개 — 실제 플레이 목표와 분기

진행 형식: `npc_id.bond_01`은 첫인사 이후, `.bond_02`는 첫 사건 및 관련 마을 상태 이후. 각 사건은 대화 + 지점 상호작용/다른 주민과 짧은 대화 중 1개 이상이 필요하다. **포커 승리가 개인 사건 완료 필수가 아니다.** 보상은 친밀도+8(최초 1회), 기념품/추가 대사 일부, 칩은 아래에 명시되지 않은 한 없음.

| 주민 | bond_01: 행동·대화 | bond_02: 행동·대화 | 결과 반응 |
|---|---|---|---|
| 루미 | 집의 빈 장식 자리 보여 주기→다시 광장 인사 | 카일에게 친목 모임 의견 전하고 돌아오기 | 등불 배치 후 초대 대사 |
| 모아 | 카드룸의 족보 안내판 2개 조사→모아에게 설명 문구 선택 | 노아 우편물에서 모임 안내문 회수 | 초보자 안내판 변경 |
| 세라 | 잡화점 선반에서 불씨 꾸러미 받기→루미 전달(기존 의뢰와 중복 지급 금지) | 비비 공방에서 낡은 등불 수선 부품 전달 | 조명 재고 및 장식 대사 |
| 카일 | 독서 쉼터 규칙판의 모호한 설명 두 곳 읽기 | 루미와 토론 뒤 쉬운 용어 안내 1개 선택 | 모임 참가 안내 개선 |
| 노아 | 우편함의 젖은 봉투 2곳 조사 | 모아에게 옛 초대장의 빈 칸 읽어 주기 | 우편함 전시 글 변경 |
| 리라 | 찻집 손님 자리 2곳 살피고 선호 묻기 | 테오에게 오래된 찻잔 덮개 부탁 전하기 | 찻집 모임 새 대사 |
| 테오 | 쿠션 헝겊 견본 2개 고르기 | 리라의 모임에 쓸 천막 패턴 전달 | 행사 장식 후보 해금 |
| 비비 | 공방의 낡은 의자/새 의자 중 수선 대상 선택 | 율과 공공 벤치 배치점 비교 | 공방 전시 변화 |
| 엘라 | 숲길 문양 안내판 2개 읽기 | 하루에게 새 지도 표식 전달 | 산책 해설 대사 |
| 하루 | 둔치에서 어두운 구간 2개 발견 | 오나와 빛 세기 1개 선택 | 밤길 등불 상호작용 |
| 주노 | 광장 게시판 글 중 난해한 표현 2개 수정 | 미리와 행사 진행 순서 선택 | 축제 사회 대사 |
| 미리 | 예산표에서 집/공공 구분 2항목 정리 | 주노와 비용/환영 문구 합치기 | 공공사업 설명 명료화 |
| 오나 | 숲길의 지나치게 밝은 조명 2개 확인 | 하루와 안전/풍경 균형 선택 | 밤길 조명 톤 플래그 |
| 렌 | 교환대 중복 카드 2장 출처 듣기 | 카일에게 교환 규칙 확인받기 | 교환회 도움말 변경 |
| 율 | 주거 골목 부서진 벤치 조사 | 비비와 고쳐 쓸 부품 선택 | 벤치가 맵에 등장 |
| 시아 | 방문객 숙소 첫 손님의 질문 전달 | 루미/모아 중 1명에게 초보 모임 안내 요청 | 손님 환영 대사 변화 |

## 중복 보상·상태 계약
기존 첫 등불/세라 배달과 개인 사건 `bond_01`이 동시에 완료되는 경우, 칩 보상은 기존 의뢰 `quest.sera_delivery` 한 건에서만 지급. 개인 사건은 별도의 대사/친밀/기억만 기록. 주민이 ‘낮 쉼터, 저녁 카드룸’으로 이동했다면 HUD 위치 추적, 같은 장소에 중복 복제하지 않는다.
