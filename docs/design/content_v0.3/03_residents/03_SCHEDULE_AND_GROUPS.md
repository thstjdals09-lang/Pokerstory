# 주민 시간대 스케줄 / 마을의 살아 있는 느낌

## 구조
- `day`, `evening` 2단계, NPC별 한 단계 한 장소. 기존 루미(낮 광장/저녁 카드룸), 모아(저녁 카드룸), 세라(상점)에 대한 기존 검증 유지.
- 주민의 장소 내 행동은 idle/talk/work/observe/festival 등 짧은 애니메이션 자리표시자. 화면 밖 장소에는 실제 캐릭터 노드가 없어도 상태 값은 존재한다.
- 이벤트 참여 시 `schedule_override`는 단일 장소를 **대체**한다. 기본 위치와 행사 위치에 복제하지 않는다. 행사 종료 시 기본 위치로 돌아온다.
- 플레이어가 퀘스트를 진행하다 시간대를 바꿔도 대상 주민을 놓치지 않도록 HUD/지도에 현재 위치 정보를 표시한다.

## 집단 반응
| 모임 | 참가 후보 | 변화 방식 |
|---|---|---|
| 카드룸 저녁 모임 | 루미, 모아, 카일, 렌 | 포커 진행/규칙/관전 반응; 모든 NPC가 매번 출석할 필요 없음 |
| 찻집 친구 모임 | 리라, 테오, 시아 | 관계가 열리면 대화와 초대장 추가 |
| 공방 회의 | 비비, 세라, 율 | 공공사업 준비도에 따라 오브젝트 상태 변화 |
| 축제 기획 | 주노, 미리, 노아 | 1→3막에 따라 회관 게시판 대사/배치 변경 |
| 숲길 산책 | 엘라, 하루, 오나 | 길 안전 사업 완료 전/후 반응 |

## 독립 행동의 최소 증거
NPC에게 처음 말 걸기 전에도 낮/저녁 위치가 다르고, 다른 주민을 이름으로 언급하고, 1개 이상의 주민 간 관계 이벤트가 플레이어가 보고 있지 않은 장소의 일과 변경을 반영해야 한다. 매시간 무작위 채팅·무한 경로 탐색은 목표가 아니다.
