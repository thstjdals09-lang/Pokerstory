# 상점·교환·가격·출처 설계

## 상점 루프
세라의 잡화점: 시작 등불과 기초 가구/소품. 테오의 수선점: 의상과 패치. 비비 공방: 가구 수선·주거 단계 후 가구 판매. 교환회: 중복 수집품을 NPC의 정해진 후보와 선택적으로 교환하는 싱글플레이 시스템. 포커에서 승리해야만 획득 가능한 **필수** 가구·필수 스토리 단서 금지.

## 거래 계약
- 매수: 가격 확인 → 충분한 칩/수량 확인 → 칩 차감·인벤토리 증가·도감 기록을 한 번에 저장. 메뉴 ESC 취소는 무변경.
- 교환: 두 인벤토리 수량 검증 후 양방향 원자 처리. 카드 뒷면/칩 스킨은 실물 판돈이나 실제 화폐로 교환 불가.
- 매도는 초기 범위에서는 보류한다. 수집 유일품을 실수로 처분하게 하지 않기 위해서다. 향후 매도를 넣어도 스토리 필수 아이템은 처분 제한.
- 구매 후 잔액이 0이어도 생활 아르바이트로 회복 가능해야 한다. 특정 구매로 지구 이동/기본 NPC 대화가 봉쇄되지 않도록 한다.
