# 공간·활동 해금 그래프

```text
새 게임 ─▶ 광장/집/상점/카드룸(저녁 전환 가능)
   ├──▶ 의뢰 1회 ─▶ 수선 가게
   ├──▶ 1막 단서 2개 ─▶ 우편함/독서 쉼터/전시 선반
   ├──▶ 공공사업 board_restoration ─▶ 공방/행사 게시판 확장
   ├──▶ 2막 완료 ─▶ 카드 정원/친목·대회 양 행사
   ├──▶ 공공사업 guest_cottage ─▶ 방문 NPC(싱글 전용)
   └──▶ 3막 완료 ─▶ 축제 재개최/후일담 전시
```

## 막힘 방지
- 모든 주요 지역은 해금 전에도 최소 통행 가능. 잠긴 것은 기능/실내/일부 대화이지 주요 지름길 전체가 아니다.
- `available` 조건은 메인 스토리 진행, ‘포커 승리’가 아니라 **다양한 기여 활동**에 기반한다.
- 소모품을 잘못 구매해 칩이 0이어도 광장 정리 아르바이트로 복구 가능. 주민 관계가 나빠졌다고 필수 인프라 잠금 금지.
- 해금 직후 새 주민이나 기능이 등장하면 지도/게시판/대화 중 하나에서 이를 알려준다.
