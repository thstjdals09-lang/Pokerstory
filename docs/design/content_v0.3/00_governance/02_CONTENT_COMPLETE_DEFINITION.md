# Stage 1–6 완료의 정의 / MVP가 아닌 콘텐츠 기준

**이번 목표는 새로운 마을·주민·선택·장기 활동이 서로 연결된 플레이 가능한 싱글 게임이다.** 첫 프로토타입 15분 루프를 반복하는 것만으로 단계 완료라 보고하지 않는다. 아트·사운드·상용 배포는 7단계 작업이다.

| 단계 | 완료라고 부를 수 있는 상태 | 필수 산출 |
|---|---|---|
| 1 세계관 | 문화·규칙·중심 갈등·서사 3막의 시작/중간/후일담이 실제 이벤트 조건으로 연결 | `01_world`의 상태/대사/트리거 구현 |
| 2 마을 | 5개 지구를 하나의 같은 마을로 이동, 입장 가능한 기능 공간 15개 이상, 막히는 동선 없음 | 맵 링크·포털·간판·부활/귀환점·충돌 검증 |
| 3 주민 | 주요 주민 16명 등록, 시간대 위치/역할/최소 개인 사건 2개씩, 우정/라이벌/연애/주민 간 관계 반응 작동 | 카드 16장 + 관계/이벤트 데이터 및 검증 |
| 4 생활 | 집 확장 3단계, 가구 배치·보관, 마을 공공사업 8개, 반복 활동 4종, 일회성 의뢰 16개, 수집 6범주 | 경제·퀘스트·가구·업적/도감 데이터 |
| 5 포커 | 원드로 기본 유지, 상대 10명 이상, 서로 다른 8능력, 포커 모임 유형 3종, 이벤트 대회 1종 | 능력 순서·AI 지식 제한·정산·중단 복원 테스트 |
| 6 통합 | 생활↔관계↔포커↔공공사업↔서사가 상호반응, 포커 0판으로도 주 서사 완주 가능, 파산/중단/세이브 불변식 | 4가지 플레이 경로 + 회귀 테스트 + 콘텐츠 누락 검사 |

## 수량은 제작 목표이지 자동으로 완료 아님
주민 16×개인 사건2 = 32개의 주민별 사건, 주 서사 3막, 집 확장3, 사업8, 의뢰16, 반복4, 수집 최소60개가 화면에서 획득·소비·상호작용되어야 한다. 텍스트 파일에 존재만 하면 미구현이다. 신규 기능당 최소 정상/우회/재실행 시험을 수행한다.

## 개발 작업 게이트 (사용자에게 매번 보고 요구하지 않음)
G1 자료/의존성 검증 → G2 세계/맵 → G3 주민/관계 → G4 생활 → G5 포커 → G6 통합. 개발 AI는 기술적으로 막히거나 최상위 요구사항 충돌 시에만 질문하고, 나머지는 자율 진행·커밋·푸시한다. 최종 보고는 실제 완료/테스트/미완료를 분리한다.
