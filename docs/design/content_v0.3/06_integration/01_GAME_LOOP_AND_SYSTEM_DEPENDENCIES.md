# 통합 루프 / 시스템 간 의존성

```text
마을 탐색 ─▶ 주민 인사/사건 ─▶ 의뢰/교류 ─▶ 칩/메모리/해금
   │             │                             │
   ├─▶ 일거리 ──┤                             ├─▶ 집 꾸미기 ─▶ 주민의 기억/집 초대
   │             └─▶ 포커 초대/관전/승부 ─▶ 칩 + 경쟁·우정 기억
   └─▶ 마을 사업/기여 ─▶ 공간·집단 일정/이야기 ─▶ 축제 ─▶ 일상 지속
```

## 상호 반응 필수 12개
1. 등불 배치 → 루미 반응(기존). 2. 꾸러미 전달 → 세라/루미 후속 대사(기존). 3. 광장 정리 → 미리의 광장 칭찬. 4. 포커에서 루미와 3회 대전 → 라이벌 반응(승리 요구 없음). 5. 카일과 이야기 → 루미의 모임 운영 대사 변경. 6. 우편함 수선 → 노아/모아 이동·대사. 7. 공방 해금 → 세라 재고/비비 인사. 8. 밤길 등불 사업 → 하루/오나 산책 대사. 9. 집 확장 → 율의 집 방문 대사. 10. 찻집 친목 → 리라/테오 관계 간선 변동. 11. 축제 첫 개최 → 주노/미리/카일/루미 행사 후 대사. 12. 포커 0판 축제 기여 → 모아가 관전과 정리를 인정하는 대사.

## 설계상 우선순위
주민 대사 조건은 `event flags`와 실제 월드 상태를 사용, 별도의 ‘보상 받은 척’ 플래그를 만들지 않는다. 같은 이벤트를 반복 관람해도 칩/아이템/관계 보상 중복 지급 금지. 게임 중단 후에도 발동 순서가 보존되어야 한다.
