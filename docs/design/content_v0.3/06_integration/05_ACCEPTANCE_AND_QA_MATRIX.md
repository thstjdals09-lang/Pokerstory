## 보고 형식
각 case_id: commit SHA, 사용 seed, 조작 단계(자동/수동), 스크린샷 또는 로그 경로, 통과/실패, 미구현 범위, 첫 플레이 회귀 검증 결과. **수량 맞춘 JSON만 생성하고 게임에서 이동/대화/선택/배치가 되지 않으면 실패.**

## 수동 검수는 마지막 단계에서 한 번에
개발 중 유닛/E2E는 매 단계 자동 수행하지만, 매 작은 기능마다 오너에게 재검수/스크린샷 재제출을 요청하지 않는다. 치명적 기획 충돌·저장 유실 위험 발생 시만 중단 보고.
