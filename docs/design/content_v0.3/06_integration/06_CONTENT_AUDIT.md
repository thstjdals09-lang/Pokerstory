# 콘텐츠 무결성 자동 검사 사양

## 정적 검사
- 등록된 모든 `resident_id`, `place_id`, `item_id`, `event_id`, `quest_id`, `project_id`, `ability_id`는 유일하고 참조 대상이 존재한다.
- 주민16명 각 day/evening 위치 1개 이하(모아 낮 위치 없으면 빈 값 명시), 행사 override 시 배치가 중복되지 않는다.
- 17개 공간의 portal target/spawn anchor가 유효, 현재 도달 가능한 씬에서 마을 복귀 가능.
- 신규 물품64개의 획득 경로와 도감 그룹/해금 조건이 실제 게임 행동에 연결.
- 주민 사건32개·의뢰16개·사업8개·직업4개·능력8개·상대10개는 이벤트/화면 참조가 존재.
- 연애 선택지는 성인 설정된 네 명만, 동의 플래그 필수, 거절 이후 필수 스토리 차단 없음.

## 동적 검사
전제 플래그를 무작위 순서로 설정해 1·2·3막 도달 가능성을 검사. ‘포커 경기 0판’ 경로를 통과하는지 별도 검증. 같은 이벤트 2회 호출 시 원장/수집/사업/관계 보상 증가가 1회뿐임을 검증. 손패 복원시 덱 순서/능력 결과 불변.

## 실패 처리
필수 데이터 누락은 보고 후 해당 기능만 안전하게 잠그고, 최초 마을/아르바이트/집/기본 상점은 계속 접근 가능하게 한다. 구세이브를 자동 삭제·초기화하지 않는다.
