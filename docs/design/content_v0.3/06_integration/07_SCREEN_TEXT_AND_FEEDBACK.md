# 콘텐츠가 작동하는지 화면에서 읽히는 최소 UX (아트 완성 아님)

## HUD 우선순위
칩 잔액/현재 시간대/장소는 상시. 플레이어가 추적 선택한 의뢰 1건과 스토리 다음 행동 1개를 접을 수 있게. 최상단에 수령 중인 꾸러미 등 필수 소지 상태를 별도로 표시. 동시에 16개 의뢰를 화면 상단에 나열하지 않는다; 전체 목록은 게시판/일지에서 확인.

## 문구 예시
- 참가금 부족: “20칩이 필요해요. 광장 아르바이트나 주민 부탁을 먼저 해 볼까요?” (포커 참여를 강요하지 않음)
- 포커 패배: “이번 판의 20칩을 잃었어요. 마을에서 다른 일을 하며 다시 모을 수 있어요.” (+20 보상 지급 금지)
- 주민 이동: “루미는 낮에는 광장, 저녁에는 카드룸에 있어요.”
- 한 번 완료된 의뢰: “이미 전해 줬어요. 고마워요!” 추가 보상 없음.
- 공공사업 기여: “게시판을 수선했어요. 공방에서 새 이야기를 들을 수 있어요.” 기능 변화 함께 표시.
- 축제 선택: “참가하지 않아도 괜찮아요. 관전하거나 준비를 도울 수도 있어요.”

## 생활 효과 피드백
가구 배치 확정 후 인벤토리 개수·집 실제 장식·주민 후속 대사 모두 업데이트. 마을 사업 완료 후 월드 지도와 해당 NPC 대사 중 **둘 다** 변화. 단순 알림 텍스트만 변경하고 씬에 기능 오브젝트가 없다면 미완성.

## 임시 그래픽 기준
스프라이트를 아직 만들지 않아도 5지구 출입구/간판/활성 상호작용은 형태·텍스트로 알아볼 수 있어야 한다. 플레이어가 왜 문에 들어갈 수 없는지 명확한 이유 제공. 현재 1280×720 기준 HUD 오버랩을 재현하지 않도록 인터랙션/카드 UI 우선순위 테스트. 최종 아트 검수는 7단계 이후.
