## 부정 테스트
1. 플레이어가 카일보다 루미와 먼저 친해져도 둘 다 이벤트 발생. 2. 카드룸 미입장 상태에서 3막 완주. 3. 칩0에서 메인 진행. 4. 사업을 먼저 완료한 상태에서 스토리 플래그 지연 반영. 5. 관련 NPC가 저녁 다른 장소로 이동했을 때 의뢰 영구 막힘 없음. 6. 연애 거절해도 서사 전 단계 접근.
