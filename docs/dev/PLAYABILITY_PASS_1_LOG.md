## 테스트 조정(이 패스 때문)
- 게시판 포커 연습 → 카드룸 게시판 연습(cc08, cc09 표)
- 한 가지 시스템을 보는 시나리오는 주민 이야기 동시 개수를 테스트 설정에서 바꿈(`Game.open_stories_max`): 부탁·알바(life), 포커(cc08), 반응(react), 저장 실패(savefail)는 0, 관계 경로(cc06)는 제한 없음. 게임 자체는 항상 3
- life: 이야기에 속한 부탁을 먼저 처리하고, 주노의 축제 준비 장면(메인)을 먼저 봄
- cc08: 카일의 규칙 부탁을 끝낸 상태에서 초대 포커. cc11: 가게는 가게 안에서, 주인이 다른 주제가 있으면 진열대에서
- path_a에 가벼운 확인 3개: 첫 아침 신호는 루미 하나, 게시판 선택지 3개, 등불 뒤 열린 이야기 3개 이하·메인 신호 1·이야기 신호 2 이하
