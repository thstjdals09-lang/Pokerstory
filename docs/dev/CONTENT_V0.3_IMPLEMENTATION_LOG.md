## 호환·우선순위 결정 (00_governance/01 규칙에 따른 기록)

팩의 제안이 기존 구현·승인과 충돌하거나 해석이 필요한 부분입니다. 기존 결정을 우선하고, 팩의 신규 내용은 기존 동작을 깨지 않는 범위에서 적용합니다.

| # | 팩 내용 | 구현 결정 | 이유 |
|---|---|---|---|
| C1 | 플레이어 집은 주거 골목, 잡화점은 장터 지구 소속 | 집·잡화점·카드룸의 **문은 기존대로 광장에** 둡니다. 장소 레지스트리에는 팩의 지구 소속을 그대로 기록합니다. | 팩의 "기존 scene ID를 깨지 않는다" 규칙과 기존 세이브의 위치·스폰 호환을 위해서입니다. |
| C2 | 별빛 감각 ID `ability.starlight_sense` | 기존 ID `ability.star_sense`를 유지하고, 팩 ID를 별칭으로 매핑합니다. | 팩 02_ABILITIES_8의 "기존 ID가 다르면 보존" 규칙 |

## Stage 1–2 — 세계관(주 서사)과 마을

엔진 공용 부분(조건식, 효과 실행기, 세이브 v4, 대사 우선순위, 주민 스케줄)도 이번 커밋에 함께 들어갑니다. 이후 단계가 이 부분을 공유하기 때문입니다.

### 구현된 것
- **서사 데이터**: `game/data/dialogue/story.json`에 프롤로그 종료(`story.prologue_complete`)부터 1막(사라진 초대장: 우편함·숲길 안내판 두 곳 단서 → 광장 카드룸 게시판), 2막(루미·카일 두 입장 → 찻집 의자 3개 또는 규칙판 3항목 준비 → 낮 둔치에서 선택 3가지), 3막(주노·모아 준비, 축제 의뢰·공공사업·첫 포커 모임 중 기여 3개 → 회관 주민 회의에서 문양 선택 → 저녁 축제 부스: 관전·정리 돕기·인사·대회), 후일담(다음 날 아침 루미)까지 들어 있습니다. 모든 단계가 플래그와 조건으로 이어집니다.
- **포커 없이 완주**: 모든 막은 포커 없이도 진행됩니다. 축제에서 포커 대회는 네 가지 선택지 중 하나일 뿐입니다.
- **HUD 목표·게시판 소식**: 막마다 다음 행동을 목표로 보여 줍니다. 게시판의 '마을 소식'은 단서·준비·기여 현황과 공공사업·집 단계를 보여 줍니다.
- **마을**: 지구 5개(광장·주거 골목·장터·숲길·둔치), 장면 15개, 기능 공간 17개(`places.json`)가 있습니다. 광장 네 방향 출입구로 오가고, 건물 문·실내 출구가 있으며, 잠긴 문은 이유(필요한 사업·의뢰·집 단계)를 알려 줍니다. 카드룸은 저녁에만 열리고, 낮에는 "저녁까지 기다리기"로 들어갈 수 있습니다.
- **세이브 v4**: v3 → v4 변환 시 칩·아이템·배치·의뢰·만난 주민을 모두 유지합니다. 등불 반응을 이미 본 세이브는 프롤로그를 끝낸 것으로 처리합니다. v1·v2 변환 경로와 v2 특별 판 1회 규칙(R2)은 그대로입니다.

### 테스트 (모두 통과)
- 단위 67개. 새로 추가된 `tests/unit/test_content_world.gd`는 5지구·17공간, 모든 장면 도달·귀환, 스폰이 충돌체 안에 있지 않은지, 대사 데이터로 본 포커 0판 주 서사 완주, 막별 목표, v3→v4 변환을 확인합니다.
- E2E `cc04`(278개 확인): 실제 입력과 문으로 15개 장면 이동, 도착 후 걷기, 잠긴 문 안내, 17개 공간 입구 사용, 시간 유지, 지구 안에서 저장한 뒤 이어하기.
- E2E `story`(230개 확인): 새 게임 → 아르바이트 → 등불 구매·배치 → 루미 반응 → 1·2·3막 → 축제 관전 → 다음 날 아침 후일담까지 UI로 진행하며, 포커는 0판입니다.
- 기존 첫 플레이 E2E 8개 시나리오도 모두 통과합니다 (원장 사유 `job:<id>:<회차>`, 세이브 버전 표기만 갱신).
- 테스트 중 발견해 고친 것: 광장 숲길 출입구 도착 지점에 나무가 놓여 있던 문제.

## Stage 3 — 주민

### 구현된 것
- **주민 16명**(모두 성인): 낮·저녁 위치가 한 곳씩 정해져 있습니다. 덮어쓰기 규칙은 위치를 바꿀 뿐 두 번째 사본을 만들지 않습니다. 2막의 루미·카일 둔치 이동, 잠긴 동안의 비비·시아 위치가 여기에 해당합니다 (C8).
- **대사**: 주민마다 첫인사, 낮·저녁 일상 대사, 포커·기억·마을 변화·축제 반응이 있고, 일부 주민은 짝 관계·라이벌 장면이 더 있습니다. 대사 항목은 `dialogue/residents.json`에 153개입니다.
- **개인 사건 32개**(주민마다 2개): 주민이 "이야기 나누기"로 제안하면, 실제 대상(다른 주민이나 마을 사물)에서 두 가지 선택지 중 하나를 고르고 응답을 듣습니다. 끝나면 친밀도 +8과 기억이 한 번만 쌓입니다. 첫 번째 사건 중 7개는 포커 능력을 하나씩 엽니다.
- **관계 축 분리**: 친밀도와 라이벌은 따로 변합니다. 라이벌 장면은 친밀도를 건드리지 않습니다.
- **선택형 연애**: 루미·카일·리라·테오 4명만 해당하며, 두 번째 사건을 마친 뒤 **플레이어가 고를 때만** 시작됩니다. 흐름은 데이트 두 번 → 함께 / 동료로 결정 → 언제든 정리 가능입니다. 거절하면 비용 없이 다시 묻지 않고, 정리해도 친밀도는 그대로입니다.
- **주민 짝 관계 10개**(`relations.json`): 사건으로만 단계가 바뀌고, 상대 주민이 그 변화에 반응합니다. 루미·카일은 2막 이야기에서 조율됩니다.
- 전용 화면이 있는 사물(집 설계도·공공사업 게시판)에서도, 여기서 끝낼 사건이 있으면 먼저 알려 줍니다. 선택지에 작별이 없는 대사에는 "그만두기"가 자동으로 붙습니다.

### 테스트 (모두 통과)
- 단위 74개. 새로 추가된 `test_residents.gd`는 16명·한 곳씩 배치, 첫인사·일상·반응 4종, 사건 32개(주민마다 2개) 완료·중복 완료 불가·보상 한 번, 친밀도/라이벌 분리, 연애 수락·데이트·결정·정리·거절, 짝 관계 변화와 반응을 확인합니다.
- E2E `cc05`(1072개 확인): 낮과 저녁에 15개 장면을 돌며 주민이 한 번씩만 있는지 확인하고, UI로 16명 첫인사, 사건 32개를 제안 → 수락 → 대상에서 선택 → 완료까지 진행합니다. 능력 8개가 열립니다.
- E2E `cc06`(144개 확인): 라이벌 장면(친밀도 불변), 카일 연애 수락 → 데이트 2번 → 함께 → 정리, 루미 연애 거절(다시 묻지 않음), 모아·노아 짝 관계 형성과 노아의 반응.
- 테스트 준비 단계에서는 장소 잠금(등불 배치, 1막 도달, 공방·객실 개방)만 상태로 설정합니다. 이 부분은 `story`·`cc04`가 실제 플레이로 검증합니다. 포커 대전 수로 오르는 라이벌은 Stage 5에서 연결합니다.

## Stage 4 — 생활

### 구현된 것
- **집 확장 3단계**: 설계도(집 안)에서 칩으로 넓힙니다.
  - 아늑한 방: 90칩, 자리 8곳.
  - 넓은 집: 180칩, 작은 방이 열려 +8곳.
  - 모임 공간: 320칩, 모임방이 열려 +8곳, 2막 완료가 조건.
  - 각 방에 '방 꾸미기' 지점이 있습니다. 가구·장식·기념품만 놓을 수 있고(옷·카드 뒷면·칩 장식은 착용), 한 자리에는 하나만 놓입니다.
- **공공사업 8개**: 마을 회관 게시판에서 후원하며, 사업마다 마을에 실제 변화가 생깁니다.
  - 게시판 수선 → 공방 개방, 비비 입주.
  - 광장 벤치 → 광장 벤치와 기념품.
  - 손님 객실 → 객실 개방, 시아 입주.
  - 장터 가림막 → 가림막과 공방 신상품.
  - 우편함 화단 → 화단.
  - 밤길 등불 → 숲길 등불.
  - 카드룸 테이블 추가 → 연습 테이블 (C9).
  - 축제 장식 → 광장 가랜드.
  - 사업마다 주민 반응 대사가 있고, 3막에는 축제 기여로도 한 번 셉니다.
- **아르바이트 4종**, 모두 반복할 수 있고 끝까지 마쳐야 보수를 받습니다. 원장에는 `job:<id>:<회차>`로 남습니다.
  - 광장 줍기(10칩)와 선반 정리(10칩, 쪽지와 다른 물건은 거부): 장소를 벗어나면 보수 없이 취소됩니다.
  - 우편 배달(12칩): 받는 사람에게 전하면 끝납니다. 마을을 이동해도 취소되지 않습니다.
  - 숲길 등불 점검(12칩): 숲길을 벗어나면 보수 없이 취소됩니다.
- **의뢰 16개**: 세라의 첫 부탁(D4, 첫 만남 대사 안)과, 주민이 "부탁 듣기"로 제안하는 15개입니다. 대상 주민에게 건네면 보수를 한 번 받고, 3막 중이면 축제 기여가 됩니다.
- **아이템 64개 / 6범주**(가구·장식·옷·카드 뒷면·칩 장식·기념품, 범주마다 8개 이상), 기존 등불 포함 65개입니다.
  - 모든 아이템에 획득 경로가 있습니다: 상점 4곳(해금 조건), 교환 4건(중복품 2개 → 새 물건, 한 번씩), 이야기·사업·사건 보상, 대회 우승 카드 뒷면(판매 안 함).
  - 도감에서는 발견·보유·배치·착용을 따로 보여 주고, 착용하기/해제가 있습니다.
  - 착용한 옷은 캐릭터, 카드 뒷면은 포커 카드, 칩 장식은 HUD 칩 표시에 임시 도형으로 보입니다.
- **메뉴**: 도감(6범주 탭), 일지(진행 중인 부탁·이야기, "따라가기"로 HUD 추적 변경), 이웃(친밀·라이벌·함께한 판·연애 단계·기억).
